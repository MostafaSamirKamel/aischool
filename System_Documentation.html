تثبيت واستخدام النظام خطوة بخطوة

الخطوة 1
شروط النظام والتثبيت
المتطلبات:
  • PHP 8.3 أو أحدث
  • MySQL 8 أو أحدث
  • Node.js 18+ وnpm
  • Composer
الخطوة 2
استنساخ المشروع وتثبيت المكتبات
git clone <repository-url>
cd "Ai School"
composer install
npm install
الخطوة 3
إعداد البيئة وقاعدة البيانات
cp .env.example .env
php artisan key:generate
php artisan migrate:fresh --seed
الخطوة 4
تشغيل النظام
نافذة طرفية 1:
php artisan serve
نافذة طرفية 2:
npm run dev
الوصول إلى:
http://127.0.0.1:8000/admin
الخطوة 5
بيانات الدخول الافتراضية
البريد الإلكتروني:
admin@example.local
كلمة المرور:
password

أو استخدم أي بيانات معرفة في seeders

نصائح مهمة
  • استخدم الأوامر الموجودة في terminal فقط، لا تستخدم صيغ أخرى
  • تأكد من تثبيت جميع المتطلبات قبل البدء
  • استخدم قاعدة بيانات منفصلة للتطوير
  • لا تشارك بيانات الدخول في الإنتاج
  • قم بنسخ احتياطي من قاعدة البيانات بانتظام

الأسئلة الشائعة

Super Admin: مدير النظام الذي يدير جميع المؤسسات والأدوار والصلاحيات وله وصول كامل لكل شيء.

Admin: مسؤول المؤسسة الفردية الذي يدير جوانب مؤسسته فقط دون الوصول لإدارة الأدوار أو المؤسسات الأخرى.

نعم، النظام يدعم تعديل الأدوار والصلاحيات من خلال لوحة التحكم، لكن فقط المسؤولون بصلاحيات كاملة يمكنهم القيام بذلك.

Multi-Tenancy يعني أن النظام الواحد يمكن أن يخدم عدة مؤسسات بنفس الوقت مع عزل كامل للبيانات بينهم. كل مؤسسة ترى بيانات نفسها فقط.

النظام يدعم عدد غير محدود من المستخدمين. الأداء يعتمد على مواصفات الخادم وقاعدة البيانات.

النظام الحالي يدعم تسجيل المدفوعات يدويًا. يمكن إضافة بوابات دفع مثل Stripe أو Fawry في المستقبل.

## 1. Visual Evolution Matrix

| Area | Before Styling Unification | After Master Design System Unification |
|:---|:---|:---|
| **Employee Sidebar** | White background (`#FFFFFF`), light gray borders, inconsistent active markers | **Dark Navy (`#162746`)**, off-white text (`#E2E8F0`), AI School Brand Green active bar (`#58BA47`) on the right (RTL) |
| **Topbar (Header)** | Varying heights (56–74px), lacking instant theme switch button | Standardized **62px compact header**, integrated breadcrumbs, dynamic Sun/Moon theme toggle |
| **Typography** | Inconsistent mix of Cairo and Alexandria without standardized hierarchy | **Tajawal** Google Font globally applied with standard font scale (24px H1, 14px body, 26px KPI) |
| **Data Tables** | Disparate row paddings, raw numbers without tabular alignment | **Medium Density (48–52px)**, uppercase slate headers, tabular lining numerals, rounded status pills |
| **KPI Stat Cards** | Variable radii, flat styling | **14px border radius**, 18px padding, bold 26px figures, elevated hover drop-shadow |
| **Forms & Controls**| Inputs of various heights (36px to 50px) | **Standard 42px height**, 8px border radius, royal blue focus ring (`0 0 0 3px rgba(54, 79, 172, 0.2)`) |
| **Modals** | Risk of overflowing smaller laptop viewports | Constrained to **`90vh`** with scrollable inner container and sticky action footer |
| **Dark Mode** | Partially supported and disabled in panel providers | **100% complete optional Dark Mode** with persistent `localStorage` preference |
| **Student Portal** | Approved mobile app layout with bottom navigation | **100% PRESERVED** as the educational mobile reference |
| **Parent Portal** | Desktop-oriented table view on mobile viewports | **Aligned with Student Mobile Language**: dedicated bottom navigation bar, drawer, and child switcher |

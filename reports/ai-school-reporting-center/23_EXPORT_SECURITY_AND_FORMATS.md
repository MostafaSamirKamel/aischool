# 23. أمان التصدير وصيغ الملفات (Export Security & File Formats)

## نظرة عامة
يوفر نظام التقارير تصديراً آمناً واحترافياً بثلاث صيغ رئيسية مع معايير حماية صارمة لمنع استغلال الثغرات الأمنية مثل حقن الصيغ (CSV Formula Injection) وحماية خطوط اللغة العربية واتجاه RTL.

## معايير الأمان والتوافقية في التصدير
1. **الحماية ضد حقن الصيغ (CSV Formula Injection / CSV Injection / DDE Attack)**:
   - أي خلية تبدأ برمز تشغيلي أو صيغة مثل `=`, `+`, `-`, `@`, `\t`, `\r` يتم تطهيرها ببادئة فاصلة عليا مفردة `'` قبل كتابتها إلى ملف التصدير.
   - هذا يمنع تنفيذ برمجيات خبيثة أو استدعاء أوامر نظام التشغيل عند فتح الملف في برامج جداول البيانات مثل Microsoft Excel أو LibreOffice Calc.
2. **ترميز UTF-8 مع BOM في ملفات CSV**:
   - كتابة بايتات الترتيب `\xEF\xBB\xBF` في بداية ملف CSV لضمان فتح الملف في Excel على مختلف أنظمة التشغيل Windows و Mac دون تشويه الأحرف العربية.
3. **توليد مستندات PDF بدعم كامل للغة العربية (RTL)**:
   - استخدام قالب مخصص يعتمد خط **Tajawal** العربي الأصيل مع دعم كامل لاتجاه القراءة من اليمين إلى اليسار (`direction: rtl`).
   - تقسيم الجداول لتفادي انقطاع الصفحات وتشوه النصوص.
   - تذييل كل صفحة برقم الصفحة، اسم منشئ التقرير، وتاريخ ووقت الإصدار بالدقيقة والثانية.
4. **تصدير Excel بصيغة OpenXML (.xlsx)**:
   - استخدام حزمة صريحة لتوليد ملفات Excel متوافقة بالكامل، مع تنسيق الأعمدة الرقمية، التاريخية، والنقدية.

# 02 — المعمارية الهندسية لمركز التقارير (Reporting Architecture)

## الهيكلية التقنية لمنظومة التقارير والاستخبارات الإدارية

الموقع: `reports/ai-school-reporting-center/02_REPORTING_ARCHITECTURE.md`

---

### 1. طبقات البناء البرمجي (Architectural Layers)

تم تصميم مركز التقارير الموحد بنمط بنية الخدمة الموجهة (Service-Oriented Architecture) داخل نظام Laravel / Filament القائم:

```
+-------------------------------------------------------------------------+
|                         FILAMENT ADMIN PANEL                            |
|             ReportingCenterPage (Livewire Component & UI)               |
+-------------------------------------------------------------------------+
                                    |
      +-----------------------------+-----------------------------+
      |                                                           |
      v                                                           v
+-----------------------------+             +-----------------------------+
|    ReportingCenterService   |             |    ReportingExportService   |
| (Metric Registry & Queries) |             |  (Excel, PDF, CSV Handlers) |
+-----------------------------+             +-----------------------------+
      |                                                           |
      +-----------------------------+-----------------------------+
                                    |
                                    v
+-------------------------------------------------------------------------+
|                         ELOQUENT MODELS & SCOPES                        |
|   TenantScope, BranchIsolation, Role Ceiling, Authoritative Records    |
+-------------------------------------------------------------------------+
                                    |
                                    v
+-------------------------------------------------------------------------+
|                         DATABASE & TRANSACTIONS                         |
|   students, enrollments, payments, installments, vaults, exams, etc.    |
+-------------------------------------------------------------------------+
```

### 2. المكونات الأساسية للنظام

#### 1. طبقة واجهة المستخدم (`App\Filament\Admin\Pages\ReportingCenterPage`)
- صفحة Filament موحدة مسجلة في مجموعة "التقارير" برابط مباشر وأيقونة تنفيذية.
- إدارة الحالة (Livewire State): فلاتر التاريخ، نوع الفترة، الفرع، الكورس، المجموعة الدراسية، والخزينة.
- 16 قسماً فرعياً (Tabs) تغطي كافة الجوانب التشغيلية والمالية والأكاديمية.
- نوافذ المعاينة المعمقة (Drill-Down Modals) لفحص السجلات الفردية المولدة لكل مؤشر.

#### 2. طبقة الحسابات والمؤشرات (`App\Services\Reporting\ReportingCenterService`)
- فصل الحسابات بالكامل عن القوالب (Templates) ومنع العمليات الحسابية داخل Blade.
- إدارة الفترات الزمنية المزدوجة:
  - **Period-Based Metrics**: أحداث تمت خلال فترة معينة (تسجيلات، تحصيلات، جلسات منجزة).
  - **As-Of-Date Metrics**: أرصدة ووضع تراكمي في تاريخ محدد (أرصدة الخزائن، إعمار الديون، الأقساط المستقبلية).
- عزل الفروع والمؤسسات (`Tenant Isolation`): التحقق الصارم من `tenant_id` لمنع تسريب بيانات الفروع.

#### 3. طبقة التصدير الآمن (`App\Services\Reporting\ReportingExportService`)
- دعم تصدير ملفات Excel (`.xlsx`)، PDF (عبر `mPDF` بتنسيق عربي RTL وخط Tajawal)، و CSV بترميز UTF-8 مع تضمين الـ BOM (`\xEF\xBB\xBF`).
- حماية ضد هجمات حقن المعادلات (CSV/Spreadsheet Formula Injection) بتطهير الخلايا التي تبدأ برموز `=`, `+`, `-`, `@`.
- استقلالية صلاحيات التصدير (`export_reporting_center`) عن صلاحية مجرد العرض.

#### 4. طبقة الجدولة والتفضيلات المحفوظة (`saved_reports`, `scheduled_reports`, `report_settings`)
- إتاحة حفظ التكوينات المفضلة للمستخدمين المصرح لهم دون تخزين بيانات مكررة، وإعادة تقييم الصلاحيات لحظة استدعاء التقرير المحفوظ.
- دعم الجدولة الآلية لتجهيز المسودات التشغيلية.

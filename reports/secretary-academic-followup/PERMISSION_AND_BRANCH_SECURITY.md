### 1. الصلاحيات الممنوحة لدور السكرتيرة (Secretary Permissions)

تم تسجيل وتخصيص الصلاحيات المستقلة التالية لدور السكرتارية (`secretary`) ومديري الفروع والمشرفين:

| الصلاحية البرمجية | الغرض التشغيلي المعتمد |
|---|---|
| `view_academic_followup` | إمكانية الوصول إلى صفحة ومركز المتابعة التعليمية في القائمة الجانبية. |
| `view_exam_followup` | استعراض تبويب متابعة الامتحانات وكشوف نتائج ومحاولات المجموعات. |
| `view_homework_followup` | استعراض تبويب متابعة الواجبات والتكليفات والتسليمات المعتمدة. |
| `view_student_contact_numbers` | إظهار أرقام هواتف الطلاب وأولياء الأمور المعتمدة للسكرتيرة. |
| `create_student_followup` | إنشاء مهام متابعة يدوية جديدة للطلاب المتأخرين. |
| `view_student_followup` | استعراض مهام المتابعة الحالية وسجل التواصل الخاص بها. |
| `record_followup_contact` | تسجيل وتوثيق محاولات الاتصال والمحادثات مع أولياء الأمور. |
| `complete_student_followup` | إغلاق وإنهاء مهمة المتابعة عند حل المشكلة وتسليم الطالب. |

### 2. القيود الصارمة والممنوعات الأكاديمية (Strict Prohibitions)

> [!CAUTION]
> **ممنوعات برمجية قطعية:**  
> يُحظر منعاً باتاً منح السكرتيرة أياً من الصلاحيات الأكاديمية التخصصية التالية، سواء عبر الواجهة أو عبر طلبات خلفية (Backend Livewire Requests):
> 1. إنشاء أو تعديل الامتحانات أو بنك الأسئلة أو الإجابات النموذجية.
> 2. رصد أو تعديل أو التلاعب بدرجات محاولات الامتحانات (`ExamAttempt.score`).
> 3. تصحيح الواجبات أو تقييمها أو كتابة ملاحظات المعلم الأكاديمية.
> 4. اعتماد ونشر درجات المسودة الخاصة بالمعلم (`publish draft score`).
> 5. تعديل أو حذف السجل الأكاديمي والتاريخي للطلاب في النظام.
> 6. التدخل في الإجراءات المالية أو الخزن أو الأقساط أو التسويات.

تم فرض هذه القيود على مستوى سياسات النماذج (`Model Policies`) واستبعاد أي آليات للتعديل في مكون `AcademicFollowUpCenter`.

### 3. العزل التام بين الفروع والكيانات (Tenant & Branch Isolation)

1. **تقييد الاستعلامات بنطاق الفرع:**
   - تخضع استعلامات الفروع والمقررات والمجموعات والطلاب لنطاق `TenantScope` ونطاق `tenant_id` الخاص بالموظف المسجل.
   - إذا كان موظف السكرتارية مسجلاً في فرع القاهرة (`Cairo Branch`)، فلن تظهر له خيارات فرع دمنهور (`Damanhour Branch`) في القوائم المنسدلة.
2. **منع التسلل عبر معلمات Livewire:**
   - في حال حاول مستخدم إرسال معرّف مجموعة أو طالب يتبع فرعاً آخر، يتم رفض الطلب فورياً في `selectedBranchId` وتفريغ قائمة الطلاب.
   - تم إثبات هذه الحماية عبر الاختبار الآلي `test_branch_isolation_prevents_cross_tenant_roster_access`.
3. **حماية أرقام الهواتف من التسريب:**
   - لا يتم تضمين أرقام هواتف الطلاب وأولياء الأمور في أي تصدير عام أو كائنات عامة غير مفلترة بالفرع المصرح به.

# ROOT CAUSE ANALYSIS & ARCHITECTURAL FIXES
**Project:** AI School Management System  
**Module:** Student Group Transfer & Academic Continuity  
**Date:** 2026-10-20  
**Status:** All Defects Resolved & Verified

## 1. Summary of Identified Defects and Root Causes

| Defect ID | Issue Observed | Root Cause | Fix Applied |
|---|---|---|---|
| **DEF-01** | Group field absent on Edit Enrollment screen | `group_id` component commented out in `EnrollmentForm.php` | Restored interactive, searchable `group_id` Select with branch, course, and capacity filters |
| **DEF-02** | Group changes did not reflect in dashboards or student lists | Dual/triple representations of group assignments were out of sync | Unified sync in `StudentGroupTransferService`: updates `enrollments.group_id`, `enrollment_courses.group_id`, and `enrollment_group` pivot |
| **DEF-03** | Progress difference hard-blocked transfers | `EnrollmentCoursesWidget` threw hard `ValidationException` when sessions differed | Replaced hard-block with reactive warning banner and confirmation checkbox (`confirm_transfer_progress`) |
| **DEF-04** | Lack of independent authorization | No `transfer_student_group` permission existed; edit permission allowed arbitrary changes | Created dedicated permission, updated `EnrollmentPolicy::transferGroup()`, disabled form field if unauthorized |
| **DEF-05** | New instructor couldn't see student; old instructor lost history | `TakeAttendance.php` queried only current `enrollments.group_id` | Refactored query to load active students for future sessions while preserving historical attendees |
| **DEF-06** | Race condition under concurrent transfers | Multiple simultaneous transfers could overfill a group | Added pessimistic locking (`lockForUpdate()`) and atomic capacity validation inside `DB::transaction()` |
| **DEF-07** | Past assignments, materials, and exams disappeared | Student portal queries filtered strictly by current group ID | Updated queries to union current group resources with historical submissions/materials |
| **DEF-08** | No audit trail for administrative transfers | No table or model tracked group transitions | Created `student_group_transfers` table, migration, model, and automatic event logging |

## 2. Detailed Technical Fixes

### 2.1. Group Selector in `EnrollmentForm.php`
```php
Forms\Components\Select::make('group_id')
    ->label('المجموعة الدراسية (Group)')
    ->searchable()
    ->preload()
    ->options(function ($record, $get) {
        $branchId = $record?->tenant_id ?? auth()->user()?->tenant_id;
        $courseIds = $record?->courses()->pluck('courses.id')->toArray() ?? [];
        if (empty($courseIds) && $record?->group) {
            $courseIds = [$record->group->course_id];
        }

        $query = Group::query()
            ->where('tenant_id', $branchId)
            ->where('status', 'active');

        if (!empty($courseIds)) {
            $query->whereIn('course_id', $courseIds);
        }

        return $query->get()->mapWithKeys(function ($group) {
            $current = $group->getActiveStudentsCount();
            $max = $group->max_students ?? 20;
            $progress = $group->session_progress;
            return [$group->id => "{$group->name} | التقدم: {$progress} | الطلاب: ({$current}/{$max})"];
        });
    })
    ->disabled(fn ($record) => !auth()->user()?->can('transferGroup', $record ?? Enrollment::class))
    ->live()
```

### 2.2. Atomic Service: `StudentGroupTransferService.php`
All transfers execute within an isolated transaction using database locks to prevent race conditions:
```php
DB::transaction(function () use ($enrollment, $targetGroup, $options, $currentGroupId) {
    // 1. Lock destination group row for concurrency protection
    $lockedTargetGroup = Group::where('id', $targetGroup->id)
        ->lockForUpdate()
        ->firstOrFail();

    if ($lockedTargetGroup->isFull()) {
        throw ValidationException::withMessages([
            'group_id' => 'المجموعة المحددة مكتملة العدد ولا يوجد بها مقاعد شاغرة.',
        ]);
    }

    // 2. Synchronize all group references atomically
    $enrollment->update(['group_id' => $lockedTargetGroup->id]);

    $enrollment->enrollmentCourses()
        ->where('course_id', $lockedTargetGroup->course_id)
        ->update(['group_id' => $lockedTargetGroup->id]);

    if ($currentGroupId) {
        $enrollment->groups()->detach($currentGroupId);
        $oldGroup = Group::find($currentGroupId);
        $oldGroup?->syncCapacity();
    }
    $enrollment->groups()->syncWithoutDetaching([
        $lockedTargetGroup->id => ['enrolled_at' => now()],
    ]);

    $lockedTargetGroup->syncCapacity();

    // 3. Record immutable audit log
    StudentGroupTransfer::create([
        'tenant_id' => $enrollment->tenant_id,
        'student_id' => $enrollment->student_id,
        'enrollment_id' => $enrollment->id,
        'from_group_id' => $currentGroupId,
        'to_group_id' => $lockedTargetGroup->id,
        'transferred_by' => $user->id,
        'reason' => $options['reason'] ?? null,
        'academic_progress_snapshot' => [...],
        'transferred_at' => now(),
    ]);
});
```

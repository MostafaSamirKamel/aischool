# أمن وسرية البيانات المالية ورؤية القراءة فقط
## AI SCHOOL — FINANCIAL READ-ONLY SECURITY REPORT

---

## 1. مبدأ الصلاحية المستقلة (Independent Financial Permission)
- البيانات المالية للطلاب (الأقساط ومواعيد السداد) محمية بصلاحية مستقلة تماماً:
  ```
  view_student_financial_follow_up
  ```
- **حيازة دور السكرتيرة أو مسؤول المتابعة لا تمنح تلقائياً صلاحية الرؤية المالية.**
- يقوم المدير بمنح هذه الصلاحية بشكل صريح ومستقل للموظف الذي تتطلب مهامه تذكير أولياء الأمور بالأقساط المتأخرة.

---

## 2. نطاق البيانات المسموح بمطالعتها (Permitted Read-Only Scope)
يحق للموظف المصرح له مالياً رؤية:
1. رقم القسط وتاريخ استحقاقه `due_date`.
2. قيمة القسط الكلية `amount`.
3. المبلغ المسدد `paid_amount`.
4. المبلغ المتبقي `remaining`.
5. حالة القسط الرسمية (`pending`, `overdue`, `partial`).
6. الكورس والمجموعة ذات الصلة بالقسط.

---

## 3. العمليات المالية المحظورة تماماً على موظفي المتابعة (Strictly Forbidden Actions)
يُحظر على موظف المتابعة والسكرتارية حظراً باتاً ومحمياً بالسياسات الأمنية (Backend Policies) والـ Middleware:
1. **تحصيل الأموال أو تسجيل سندات قبض.**
2. **تعديل مبالغ الأقساط أو تخفيضها.**
3. **تغيير حالة القسط إلى "مسدد" أو "ملغى".**
4. **تعديل قيود المحاسبة ودفاتر الأستاذ.**
5. **إصدار استرداد مالي (Refunds).**
6. **الاطلاع على أرصدة الخزائن (Vault Balances).**
7. **الاطلاع على حركات وتحويلات الخزائن (Vault Transactions).**
8. **الوصول إلى سجلات المرتبات ومستحقات المعلمين.**

---

## 4. إقرار ولي الأمر الشفوي لا يغير الحالة المالية
- إذا أفاد ولي الأمر أثناء المكالمة الهاتفية بأنه قام بالسداد أو التحويل:
  - يُسجل ذلك كملاحظة نصية في سجل الاتصال فقط.
  - **لا تتغير الحالة الرسمية للقسط إطلاقاً بناءً على المكالمة.**
  - تظل حالة القسط خاضعة حصراً للنظام المالي ولتأكيد مسؤول الحسابات والخزينة المعتمد.

---

## 5. الحماية ضد تسريب البيانات (Data Leak Prevention)
- في استعلامات API و Livewire payloads:
  - إذا كان المستخدم يفتقر لصلاحية `view_student_financial_follow_up`:
    - يتم استبعاد إنذارات الأقساط بالكامل من مجموعة البيانات المعادة.
    - يُعاد مصفوفة فارغة `[]` لقائمة الأقساط في ملف الطالب.
    - تُعطل كافة أزرار وعناصر الواجهة المرتبطة بالبيانات المالية.

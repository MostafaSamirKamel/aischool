# تقرير تنفيذ مركز متابعة الطلاب اليومي الموحد
## AI SCHOOL — UNIFIED DAILY STUDENT FOLLOW-UP CENTER
### IMPLEMENTATION OVERVIEW REPORT

---

## 1. الملخص التنفيذي
تم تطوير وبناء **مركز متابعة الطلاب اليومي الموحد (Unified Daily Student Follow-Up Center)** كواجهة مركزية موحدة وشاملة داخل لوحة الإدارة المعتمدة في **AI School** (`/admin/academic-follow-up-center`).

يسمح هذا المركز لموظف السكرتارية أو المشرف التعليمي أو مدير الفرع بإدارة ومراقبة كافة المشكلات الأكاديمية (غياب، واجبات غير مسلّمة، تسليمات متأخرة، درجات ضعيفة، امتحانات متخلف عنها، أقساط متأخرة) ومتابعتها من خلال **شاشة واحدة متكاملة** وتصميم عربي RTL أنيق وتفاعلي عبر Laravel و Filament و Livewire.

---

## 2. أقسام الشاشة الرئيسية (Core Navigation Sections)

تم تنظيم المركز في 5 أقسام رئيسية واضحة ومباشرة دون تعقيد أو تشتيت للموظف:

1. **متابعة اليوم (Today's Follow-Up):**
   - بطاقات المؤشرات الرئيسية (KPI Cards) بعدد 8 بطاقات تفاعلية:
     - الطلاب المحتاجون متابعة
     - حالات جديدة
     - تم التواصل
     - واجبات لم تُسلّم
     - درجات ضعيفة
     - غياب الطلاب
     - امتحانات لم تُحل
     - محاولات تواصل اليوم
   - جدول الإنذارات الأكاديمية اللحظي (Active Alerts Table) مع فلاتر سريعة بنوع المشكلة والبحث باسم الطالب أو رقم الهاتف.
   - عمود منفصل لكل من: **موبايل ولي الأمر** و **موبايل الطالب**.
   - إجراءات سريعة: عرض ملف الطالب، إنشاء متابعة، تسجيل محاولة تواصل.

2. **ملفات الطلاب (Student Profiles):**
   - استعراض قائمة الطلاب المصرح للموظف بمتابعتهم.
   - عرض فوري وشامل لملف المتابعة الكامل للطالب (بيانات الحضور، الواجبات، الامتحانات، سجل المتابعات، والأقساط للقراءة فقط).

3. **حالات المتابعة (Follow-Up Cases):**
   - جدول الحالات المفتوحة التي تم إنشاؤها يدوياً.
   - يقتصر حصراً على الحالتين المعتمدتين: **جديدة** و **تم التواصل**.
   - عرض الموظف المسؤول وإمكانية إعادة التكليف أو استعراض سجل الاتصالات.

4. **سجل التواصل (Communication History):**
   - جدول زمني مستقل يسجل كل محاولة اتصال هاتفية أو عبر واتساب مع النتيجة (تم التواصل، لم يرد، الرقم غير متاح) والملاحظات واسم الموظف القائم بالمحاولة.

5. **التقارير اليومية (Daily Reports):**
   - تقرير تشغيلي إحصائي متكامل لليوم المختار يوضح توزيع الحالات، نسب التواصل الناجح وغير الناجح، وحجم الإنجاز لكل موظف.

# تنفيذ التسليمات المتأخرة وقواعد قبولها
## Late Submission Implementation & Lifecycle Rules

---

### 1. القرار المعتمد (The Approved Policy)

وفق متطلبات النظام التعليمي الصريحة:
> **"يُسمح للطلاب برفع وتسليم الواجبات بعد انقضاء موعد الاستحقاق (Late Submissions Allowed)، ما دام الواجب سارياً ولم يُغلق يدوياً بقرار إداري. ولا يجوز للباك إند رفض رفع الحل لمجرد أن `now() > due_date`."**

---

### 2. الآلية التقنية للتسليم المتأخر (Technical Mechanism)

1. **قبول الرفع في `HomeworkService::submitHomework()`:**
   - تم التحقق من أن دالة رفع وتسليم الواجب تستقبل الملفات وتنشئ أو تحدث سجل `AssignmentSubmission` دون إطلاق أي استثناء بسبب انتهاء الموعد.
   - يتم تخزين الطابع الزمني الفعلي للتسليم في عمود `submitted_at = now()`.
   - لا يتم العبث بتاريخ استحقاق الواجب الأصلي `Assignment.due_date` لإظهار الطالب وكأنه في الموعد.
2. **الاحتفاظ بالدليل الزمني الدائم:**
   - تحتسب دالة `isLate()` بموديل `AssignmentSubmission`:
     ```php
     public function isLate(): bool
     {
         if (!$this->submitted_at || !$this->assignment?->due_date) {
             return false;
         }

         $dueDate = Carbon::parse($this->assignment->due_date)->endOfDay();
         return Carbon::parse($this->submitted_at)->gt($dueDate);
     }
     ```
3. **تأثير التسليم المتأخر على الإحصائيات والأدوار:**
   - **الخروج الفوري من فئة "لم يسلّم":** بمجرد رفع الحل، يخرج الطالب من عداد "لم يسلّموا بعد" ومن قائمة "متأخر ولم يسلّم".
   - **الانتقال إلى طابور المراجعة:** يدخل الطالب فوراً في قائمة "واجبات تحتاج مراجعة" و "بانتظار التصحيح" لدى المعلم.
   - **بقاء شارة التأخير:** يظل موسوماً بشارة **"سلّم متأخرًا"** حتى بعد تصحيح الواجب ونشر النتيجة رسمياً.
   - **المزامنة مع السكرتارية:** ينعكس التحديث فوراً في مركز المتابعة الأكاديمية التابع للسكرتارية.

---

### 3. إثبات اختبارات الحدود الزمنية (Boundary Test Verification)

تم التحقق من الحالات الحدية عبر الاختبارين `TEST-004` و `TEST-013`:
- **حالة التسليم قبل دقيقة من منتصف الليل (23:59):**  
  تم تسجيله كـ `تم التسليم في الموعد` (`isLate = false`).
- **حالة التسليم بعد دقيقة من منتصف الليل (00:01):**  
  تم قبوله بنجاح وتسجيله كـ `سلّم متأخرًا` (`isLate = true`).
- **حالة إعادة التسليم (Resubmission):**  
  إذا أعاد الطالب رفع صور جديدة بعد الموعد، يُحدث الطابع الزمني ليعكس التوقيت الأخير ويظل مصنفاً كمتأخر مع إعادة تصفير حالة الاعتماد لتتطلب مراجعة المعلم مجدداً.

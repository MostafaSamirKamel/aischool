# اختبارات الأدوار والصلاحيات والأمان المتعدد
## Role, Permission, Multi-Tenancy & Authorization Security Tests

---

### 1. مصفوفة الصلاحيات (Authorization Matrix)

| الدور (`Role`) | عرض مركز مراجعة الواجبات | معاينة حلول الطلاب ومرفقاتهم | حفظ مسودة تقييم | اعتماد ونشر النتيجة | التسليم نيابة عن الطالب |
|---|---|---|---|---|---|
| **المعلم صاحب المجموعة (`Group Instructor`)** | مصرح | مصرح | مصرح | مصرح | غير مصرح نهائياً |
| **معلم مجموعة أخرى (`Foreign Instructor`)** | مصرح للوحته فقط (محظور للمجموعات الأجنبية) | محظور | محظور | محظور | غير مصرح |
| **السكرتيرة (`Secretary`)** | محظور (تستخدم مركز المتابعة فقط) | مصرح للاطلاع فقط | **محظور قطعياً** | **محظور قطعياً** | غير مصرح |
| **الطالب (`Student`)** | محظور | يرى واجبه فقط بعد النشر | محظور | محظور | يرفع حله بنفسه فقط |
| **المشرف / المدير (`Super Admin`)** | مصرح للمراقبة العامة | مصرح | مصرح | مصرح | غير مصرح |

---

### 2. محددات الأمان الصارمة المنفذة (Enforced Security Constraints)

#### أ. حظر تسليم الواجب نيابة عن الطالب (No Proxy Submissions)
- بناءً على التوجيه الأمني الصريح، **لم تتم إضافة أي ميزة أو زر يتيح للمعلم رفع حل نيابة عن الطالب**.
- التسليم هو إجراء حصري ومسؤولية كاملة للطالب عبر بوابته الخاصة لضمان النزاهة الأكاديمية وصحة الأدلة الرقمية.

#### ب. عزل الفروع والمؤسسات (`Multi-Tenant Isolation`)
- يتم تطبيق نطاق `tenant_id` على كافة استعلامات الواجبات والتسليمات والطلاب.
- لا يمكن لمعلم في "فرع القاهرة" الوصول أو استعراض أو تقييم طلاب "فرع دمنهور" حتى لو امتلك الرابط المباشر.

#### ج. التحقق من ملكية الواجب والمجموعة (`Instructor Ownership Verification`)
- استعلام الواجبات في لوحة المعلم محصور بالمجموعات التي يديرها المعلم المسجل:
  ```php
  $query->where(function ($q) use ($instructor, $user) {
      $q->where('assignments.instructor_id', $instructor->id)
        ->orWhere('assignments.instructor_id', $user->id)
        ->orWhereHas('group', function ($g) use ($instructor) {
            $g->where('instructor_id', $instructor->id);
        });
  });
  ```
- عند محاولة معلم اختيار معرف واجب لا يخصه، يتم إرجاع إشعار تحذيري ورفض فوري للطلب (`TEST-010`).

#### د. حظر حقوق التقييم عن السكرتارية (`Secretary Grading Guard`)
- تم تحصين دوال الخدمة `saveDraftGrade` و `publishGrade` بالتحقق من الدور:
  ```php
  if ($grader && $grader->hasRole('secretary')) {
      throw new AuthorizationException('غير مصرح للسكرتارية باعتماد أو نشر درجات الواجبات.');
  }
  ```
- تم التحقق من الرفض باختبار `TEST-011`.

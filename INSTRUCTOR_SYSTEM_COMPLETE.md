## 📊 Database Schema

```sql
instructors
├── id (bigint, primary key)
├── user_id (foreign key → users)
├── tenant_id (foreign key → tenants)
├── department_id (nullable, foreign key → departments)
├── employee_code (varchar 50, unique)
├── specialization (varchar 255)
├── bio (text)
├── qualifications (json)
├── years_of_experience (integer, default 0)
├── status (enum: active, inactive, on_leave, default active)
├── hired_date (date)
├── contract_type (enum: full_time, part_time, contract, default full_time)
├── salary (decimal 10,2)
├── phone (varchar 20)
├── emergency_contact (varchar 255)
├── created_at (timestamp)
├── updated_at (timestamp)
└── deleted_at (timestamp, nullable)

Indexes:
- instructors_tenant_id_index
- instructors_user_id_index
- instructors_department_id_index
- instructors_employee_code_unique
```

## 🔗 Relationships

```
Instructor
├── belongsTo: User
├── belongsTo: Tenant (via TenantScope)
├── belongsTo: Department
└── hasMany: Group

Group
└── belongsTo: Instructor (updated from User)
```
